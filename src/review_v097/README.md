# Selected implementation snapshots

These five authored modules document the bounded inventory, Charm, ending,
MP-label and related dialogue corrections in successors307–309.
They retain their development-relative imports and paths for review.

They are not a standalone command or installed editor. The private layout,
historical compiler modules and source-derived catalogs remain required.
The Korean review input is published separately in
[the selected data directory](../../data/translations/V0.97/README.md).

For a reproducible player installation, use the cumulative V0.97 patch and
[installation instructions](../../patch/INSTALL.txt).
