LANGRISSER FX KOREAN PATCH V1.1 — STABLE RELEASE INSTALLATION

This package does not contain the original game or a patched disc image.
You must supply a legally obtained Japanese PC-FX dump.

Required original Track 2
  Representation: raw MODE1/2352 with the 225-sector pregap
  Size:           755,535,312 bytes
  SHA-256:        1013D1AECCD42BB46DEA36CF3BD088CAE02FAC5D25BF4BC0187821ACAB9F8AD0

WINDOWS AUTOMATIC INSTALLATION

1. Run Langrisser-FX-KR-Auto-Patcher-V1.1.exe.
2. Select the original Japanese .cue file. Keep all three original BIN files
   beside that CUE under the filenames referenced by it.
3. Select an output location and press the build button.
4. Open Langrisser FX Korean Patch\Langrisser-FX-KR.cue in your emulator.

The automatic patcher verifies all three original tracks, creates a separate
complete disc set, and never overwrites the originals or an existing output.

COMMAND-LINE FALLBACK

1. Install Python 3.
2. Put apply_patch.py and Langrisser-FX-KR-V1.1.lfxpatch together.
3. Run:

   python apply_patch.py "original Track 2.bin" "Track-2.KR.bin" --patch Langrisser-FX-KR-V1.1.lfxpatch

4. A successful run must report:

   Size:     762,048,000 bytes
   SHA-256:  198965A8481A97A1E0535FDC80918A0982EE643C4FFD0039F20D2C9697273580

5. Copy your unchanged original Track 1 and Track 3 into the same folder,
   named Track-1.bin and Track-3.bin.
6. Put Langrisser-FX-KR.cue in that folder and open the CUE in your emulator.
7. Keep backups and do not overwrite the original tracks.

The applier refuses an unknown source and refuses to overwrite an existing
output. If final verification fails, the incomplete newly created output is
removed.

한국어 설치 안내

이 패키지에는 원본 게임이나 완성된 게임 이미지가 없습니다. 위 크기와
SHA-256이 정확히 일치하는 일본판 RAW Track 2를 직접 준비해야 합니다.

자동 설치

1. Langrisser-FX-KR-Auto-Patcher-V1.1.exe를 실행합니다.
2. 원본 일본판 CUE 파일을 선택합니다. CUE가 참조하는 원본 BIN 3개는
   CUE와 같은 폴더에 그대로 두어야 합니다.
3. 출력 위치를 고르고 ‘한국어판 만들기’를 누릅니다.
4. 생성된 Langrisser FX Korean Patch 폴더의 Langrisser-FX-KR.cue를 엽니다.

원본과 기존 출력은 덮어쓰지 않습니다. 세 원본 트랙이 지원판과 정확히
일치하는지도 자동으로 검사합니다.

수동 설치

1. Python 3을 설치합니다.
2. 위 명령으로 원본 Track 2를 입력하고 새 Track-2.KR.bin을 만듭니다.
3. 성공 메시지의 결과 크기와 SHA-256이 위 값과 같은지 확인합니다.
4. 원본 Track 1과 Track 3을 각각 Track-1.bin, Track-3.bin으로 복사합니다.
5. 네 파일을 같은 폴더에 두고 Langrisser-FX-KR.cue를 실행합니다.

원본을 덮어쓰지 마십시오. 패처는 지원하지 않는 원본과 이미 존재하는 출력
파일을 거부합니다.

UPDATING FROM OLDER VERSIONS / 이전 버전에서 업데이트

Apply V1.1 to the supported original Japanese dump, not to an older Korean BIN.
This is a complete cumulative patch, not an incremental update patch.
Back up your SRAM saves. Copy a save to the new emulator save location/name if
needed; this package does not modify or include save files. Do not carry an
emulator save state across builds, because it can restore old patched code.

이전 한글판 BIN에 덧씌우지 말고 원본 일본판에 V1.1을 새로 적용하세요.
이번 파일은 누적 패치입니다. SRAM 세이브는 먼저 백업하고 에뮬레이터의
저장 위치·이름에 맞게 옮기세요. 기존 버전의 강제 세이브/상태 저장은
이전 코드까지 복원할 수 있으므로 사용하지 말고 게임 내 저장을 불러오세요.

RUN-HOLD SKIP / RUN 길게 누르기 스킵

Hold RUN for approximately 1.2 seconds at an eligible dialogue/narration input
wait or during a gameplay movie. Once active, connected dialogue keeps skipping
across speakers/factions even after releasing RUN. Choices, unit deployment,
movies and other real sequence transitions disarm it. Release and hold RUN again
for the next segment. Choices are not auto-selected. Omake controls are unchanged.

입력 가능한 대사·나레이션 또는 게임 중 영상에서 RUN을 약 1.2초 누르세요.
활성화 뒤에는 버튼을 놓아도 연결된 대사 전체가 계속 넘어갑니다. 선택지·유닛
배치·영상 등 진행 전환에서는 해제되며 다음 구간은 놓았다가 다시 눌러야 합니다.
선택지를 자동으로 고르지 않습니다. 짧은 자동 진행 페이지는 스킵 시작 전에
끝날 수 있습니다. 전과보고·통계·캐릭터 후일담은 이번 스킵 기능의 대상이 아닙니다.
