# V0.97 검증 범위

승인된 내부 빌드 successor309의 게임 바이트를 바꾸지 않고 V0.97 누적 패치로 배포한다.
수치와 적용 파일 해시는 [기계 판독 기록](verification_V0.97.json)을 참조한다.

## 배포 파일 검사

원본 일본판 + 고정 v0.81 누적 명세로 309를 새로 재구성하고 승인된 ISO/RAW/오디오와
전체 바이트를 대조한다. 공개 Python 패처와 배포 EXE를 각각 원본 3트랙 CUE에 적용하고
동일 결과를 확인한다. 공개 패처 회귀 테스트 11개, ZIP 허용 목록·CRC·멤버 체크섬,
원본 사진 동일성, 개인 경로·금지 매체·문서 링크를 검사한다.
게시 후 태그·본문·첨부를 재조회하고 ZIP을 다시 내려받아 로컬 파일과 대조한다.

원본 디스크·사용자 번역 JSON·첨부 SRAM은 보존했다.

## 남은 사항

간헐적인 엔딩 검은 화면은 미해결이다. 임의 사용자 이름의 받침에 대한 자동 조사
선택, 전 캠페인·모든 분기·모든 기기 호환성은 보증하지 않는다. 이전 누적 도구의
기존 실패 8개·오류 1개를 해결했다는 뜻도 아니다. 공개 저장소는 선별된 소스이며,
비공개 원본 추출 자료가 필요한 전체 게임 저작·편집기 빌드 환경이 아니다.

현재 배포에 대해 재현 가능한 공개 경로는 **지원 원본 + 누적 delta → 정확한 결과**다.
