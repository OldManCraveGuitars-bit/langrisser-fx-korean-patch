- 최종 302의 301 대비 19,100바이트 차이가 선언된 쓰기 범위와 정확히 일치합니다.
- 공용 105개 사본의 저장/구매/소지 한도/자금 문구 420개 확장과 아이템 안내 525개를 검사했습니다.
- 초 랑그 977개 제어 구조, 95개 나레이션 보존, 추가 문구 7개 외 나머지 970개

  순번/빈 행/이름 변수·게임 판정도 검사했습니다.
- 65,536개 글자 입력의 기존 경로·픽셀, 원래 화면 그림 15개, 메뉴 읽기 함수의
  호출 규약 774조합 및 관련 회귀 테스트 14개를 확인했습니다.
- 20화 이후 6,939항목, 후일담 134개/229페이지 검수는 전체 집합의 정적 대조이며
  해당 집합 전체를 실플레이했다는 뜻은 아닙니다.

## 실제 실행

- 최종 302 새 실행: 초 랑그 3장 도입, 메뉴·설정·승패 조건·저장 질문·불러오기.
- 최종 302 상점: 소지 한도, 실제 판매/구매, 대검 착용 불가 질문과 취소.
  착용 불가 캡처는 같은 빌드의 콜드 실행에서 만든 구매 직전 상태를 재개했습니다.
- 최종 302 일반 20장: 사용자 SRAM 콜드 로드, 메뉴·설정·조건·저장 질문과 지도 복귀.
- 게임 자체 장 선택으로 최종 302의 초 랑그 7개 리소스를 새로 로드하고 대사·사전·
  나레이션·조건·글꼴의 RAM 일치를 검사했습니다. 앞서 정상 획득한 해금 체크포인트를
  사용한 별도 검사이며, 7장 전체 캠페인 플레이가 아닙니다.
- 최종 302 전투: 정상 게임 저장 SRAM을 콜드 로드한 뒤 컨트롤러로만 진행했습니다.
  69~72 첫 교전, 188번 두 페이지·189/190 답변, 리치97/로우가73 사망, 소니아106,
  8턴 지도 복귀를 확인했습니다. 최종 전투 세션은 상태 로드/RAM/HP/위치/플래그 변경이 없습니다.
  입력 SRAM은 앞선 첫302의 호환 체크포인트와 정상 플레이 후 게임 자체 저장으로 획득했습니다.
- 이전 298/300/301의 그레이트 드래곤, 후일담·크레딧·아이템 안내, 엔딩 후 초 랑그 진입
  기록은 누적 수정의 출처로 구분합니다. 이를 최종 빌드의 전 구간 재주행으로 표현하지 않습니다.

The exact tested artifact and distribution-application checks are separate from
human wording approval and unplayed routes. This is a maintainer-requested
development prerelease, not a full game, all-branch or hardware certification.
