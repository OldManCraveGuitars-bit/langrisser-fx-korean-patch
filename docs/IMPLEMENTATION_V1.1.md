# V1.1 구현 요약

- 네이티브 프레임 시계로 RUN 72프레임을 판정. 대기 진입 시 카운트를 새로 시작합니다.
- 활성화 상태는 화자·진영 전환, 카메라·음성 설정, 내부 분기·호출 사이에 유지합니다.
- 실제 선택 명령 1D/43, 영상 30, 배치·퇴장·지도·행동 전환 등에서 해제합니다.
  버튼을 계속 누르고 있으면 재시작을 잠그고, 놓은 뒤 새 입력을 요구합니다.
- 음성은 원래 II 취소와 동일한 종료 경로, 영상은 원래 디코더 중단·정리 경로를 사용합니다.
  선택 입력을 합성하거나 이벤트 PC를 다음 장면으로 강제로 옮기지 않습니다.
- 의미가 같은 압축 함수의 반환 뒤 공간만 사용합니다. 부팅 시 덮어쓰이는 임시 공간은 사용하지 않습니다.
- 필드 표시 보조 코드는 기존 Resource-12 소유 공간 안에 두며 인접 글꼴은 보존합니다.
- V1.05 대비 변경은 이 기능의 코드·상태·호출 지점에 한정되며 번역·자막·음원·보상식은 유지됩니다.

[새 소스 선별본](../src/review_v11/README.md)을 포함합니다. 내부 개발 파일명은 유지합니다.
원본 게임과 비공개 작성 의존 파일은 포함하지 않으므로 이 선별본만으로 전체 게임을
소스 빌드할 수는 없습니다. 공개 재현 경로는 **지원 원판 + 누적 패치 = 확인된 최종 결과**입니다.
