# V0.972 implementation notes

`src/review_v0972/all_conditions310.py` is the unchanged authoring module used for
the accepted310 build. It operates on exact309 input, preserving fixed table and
section capacities. It prefers literal menu text, allocating only unused high
dictionary entries when necessary. Live dictionary-reference closures and low
reserved entries are protected, and unrelated expanded text is checked for equality.

Menu conditions (section6) and pre-battle presentations (section7) are separate
consumers. Both were audited. Native normal8 / alternate13 row order and empty
slots, source name operands and page/wait controls are preserved. No renderer,
glyph data, gameplay event or victory/defeat decision code is changed.

The private builder `build_all_conditions_successor310.py` asserts approved309's
exact identity, composes310 with original-derived earlier layers, and validates
the expected writes. Its final review2 build reuses a hash-verified original-derived
298 cache, not a patched309 image as input. Publication creates a fresh cumulative
source-gated delta and checks both public installers against that accepted output.

[Korean-only change data](../data/translations/V0.972/conditions310.json) contains
85 menu and11 presentation replacements, not the complete extracted Japanese catalog.
The snapshot requires private historical modules/catalogs and original media;
it is not a standalone editor build. The supported reproducible public operation is
original Japanese disc + cumulative delta = the verified target.
