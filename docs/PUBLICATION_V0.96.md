# V0.96 publication decision

The maintainer explicitly accepted the successor302-review5 result and requested
GitHub publication with screenshots and update notes under **V0.96**. This versioned
decision continues the project's existing development/prerelease review policy.
It applies to the exact RAW target SHA-256
`DD054F9B720BC5B460AA6870098AE9F6534229C3C2956B69C4CCBAEC11501EE3`.

The allowed publication is the cumulative delta, matching Windows/Python installers,
current reports, licenses and selected unedited runtime screenshots. It is not
permission to publish original/patched games, BIOS/emulator binaries, saves, states,
memory dumps, Japanese source catalogs, personal editor snapshots or private paths.
Older tags, release assets, patches and reports are preserved.

Private historical development/non-distribution input markers remain historical
facts; this decision does not silently mark every working translation or unplayed
branch fully reviewed. The package remains a **prerelease**. In particular the
intermittent ending black screen was explicitly excluded from follow-up work and
is disclosed as unresolved; all-branch/hardware completion is not claimed.

Publication requires exact original-source rebuild identity, independent Python and
packaged-EXE application to the original three tracks, allowlisted ZIP contents and
member checksums, unchanged screenshot provenance, privacy/link checks, and remote
tag/body/asset readback. A mismatch or new relevant defect stops publication.

Screenshots document reported defects and fixes. Original game imagery remains
with its rightsholders and is excluded from the project's MIT grant. See
[license scope](../LICENSE_SCOPE.md) and [screenshot provenance](../screenshots/V0.96/README.md).
