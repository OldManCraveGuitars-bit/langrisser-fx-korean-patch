# v0.86 publication scope

The maintainer explicitly requested completing the corrections, verifying Elwin
and Sherry, and publishing v0.86 with the change report and actual screenshots.
This continues the development/prerelease-review policy; it does not mark all
branches, all wording or all platforms complete.

Included: the cumulative delta, matching Windows automatic patcher, Python
appliers, installation and change/verification/implementation reports, selected
project-authored sources, Korean-only adopted wording, limited before/after
screenshots documenting these defects, and retained license notices.

Excluded: original or patched BIN/ISO files, source CUE files, BIOS, emulator
executables, SRAM and emulator states, memory dumps, extracted media collections,
private absolute-path reports, personal editor snapshots and original Japanese
catalogs. The generic patch-output CUE remains included. Existing release
archives, versioned patches, tags and reports are preserved.

Release checks use an explicit archive allowlist, member checksums and CRC/readback,
source-copy equality, canonical Git-blob manifest, privacy checks and independent
Python/packaged-EXE application to the exact supported original disc.

Screenshots are unedited runtime captures. Their original game graphics, names
and characters are not licensed under the project's MIT license.
See [license scope](../LICENSE_SCOPE.md) and [screenshot provenance](../screenshots/v0.86/README.md).
