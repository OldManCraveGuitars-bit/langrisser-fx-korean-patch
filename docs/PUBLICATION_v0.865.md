# v0.865 publication scope

The maintainer explicitly requested Scenario 18's complete omission repair,
verification using the supplied save, and GitHub v0.865 with corrected screenshots
and a report. This continues the existing development/prerelease review policy.
It is not a final-completion or all-branch certification.

Included: cumulative delta, matching Windows installer, Python appliers,
installation/change/verification/implementation reports, selected authored source
and adopted Korean text, limited actual before/after screenshots and licenses.
The new selected-text file retains its development-review/non-distribution input
marker for provenance. This explicit, versioned maintainer publication decision
authorizes this selected prerelease snapshot; it does not reclassify all private
working catalogs or other unreleased material as distributable or fully reviewed.

Excluded: original/patched BIN or ISO files, source CUE, BIOS, emulator binaries,
SRAM/state files, memory dumps, source-derived Japanese catalogs, private absolute
path reports, personal editor snapshots and bulk extracted media. The generic
output CUE is included. Older release archives, deltas, tags and reports remain.

Release gates include independent Python and packaged-EXE full-disc application,
byte-for-byte track readback, explicit ZIP allowlist, member hashes and CRC,
source-copy equality, image provenance, document links, privacy checks and a
canonical Git-blob manifest. The source snapshot still requires withheld/source-
derived dependencies for a full original-disc authoring build.

Runtime screenshots are unedited. Original game art, names and characters in
them are not covered by the project's MIT license. See
[license scope](../LICENSE_SCOPE.md) and
[screenshot provenance](../screenshots/v0.865/README.md).
