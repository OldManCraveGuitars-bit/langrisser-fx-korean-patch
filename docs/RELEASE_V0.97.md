## 디스크 확인값

**패치 적용 후 Track 2** — 다운로드 ZIP의 해시가 아닙니다.

```text
Size:     762,048,000 bytes
SHA-256:  6616EE3B5D544E9183A5A6E44BFF1BB8FC77F75D95696EEAE6DB157CD55390A8
```

**원본 일본판 Track 2** — 225섹터 프리갭을 포함한 RAW MODE1/2352 BIN입니다.

```text
Size:     755,535,312 bytes
SHA-256:  1013D1AECCD42BB46DEA36CF3BD088CAE02FAC5D25BF4BC0187821ACAB9F8AD0
```

V0.96 공개 이후 successor303~309의 수정을 모두 포함한 누적 패치입니다.
**기존 한글판에 덧씌우지 말고 원본 일본판에 새로 적용하세요.** SRAM을 백업하고
게임 내 저장을 불러오세요. 이전 빌드의 강제 상태 저장은 옛 코드까지 복원할 수 있습니다.
원본 게임·완성된 게임 이미지·BIOS·세이브는 포함하지 않습니다.

## 1. 시나리오 5의 제시카 대사 누락

`여러분께` 이후 비어 보이던 문장에서 빠진 의미를 복원하고 일본판과 같은
3페이지로 정리했습니다. 에그베르트보다 먼저 다크 로드를 얻어야 한다는
중간 문장을 복원했고, 마지막은 `저도 여러분께 / 힘을 보태겠습니다.`로 연결했습니다.
티아라·광휘의 후예 설명도 같은 페이지 안에서 자연스럽게 이어지도록 수정했습니다.

아래는 **수정 전 제보 사진**입니다. 수정 후 동일 장면 사진은 확보하지 못했습니다.
개발 검증은 최종 대사 데이터와 실제 로드를 확인했으며, 이후 사용자가 정상이라고 확인했습니다.

## 5. 엘윈 조사와 나머지 대사 검수

이름 문맥 527행을 조사해 `엘윈 는/가/를/와/라면/다` 등의 조사를 문맥에 맞게
다듬었습니다. 최근 검수 밖의 15개 챕터 2,322행도 직접 일본판과 대조했습니다.
누락 문장, 반대 뜻의 명령, 잘못된 인명·지명과 어색한 문장을 고쳤습니다.
일본어가 남아 있던 내부 분기 복제 74~78에는 원문이 동일한 검수 번역을 연결했습니다.
이 단계의 의미 변경은 1,128행이며, 그중 689행은 분기 복제 번역 복구입니다.
이 수치는 이후 50번 재교정 수치와 중복되므로 합산해 고유 오류 개수로 세면 안 됩니다.
