# v0.845 publication decision

Decision ID: `v0845-current-target-public-prerelease`.

The maintainer explicitly requested publishing the current build on GitHub as
v0.845. This continues the established public pre-release status; it does not
convert unfinished review or tests into completed work. The selected target is
the recorded Scenario 10 menu/unit-cache correction plus the ten selected
Scenario 8/9 dialogue edits and all earlier cumulative work.

Original game images, BIOS, emulator binaries, extracted graphics/audio/video,
personal saves, full private editor snapshots, runtime states/screenshots,
credentials and local account paths are excluded. The only CUE distributed is
the reviewed project-authored short-name template; it contains no game data.
The ZIP allowlist consists of the delta, patchers, installation instructions,
change history, release/technical documents and license notices.

Project-owned material remains under the existing MIT scope. No license is
granted to the original game or third-party material by this release. Private
needs-human-review and historical non-distribution markers are preserved; this
is a separate maintainer publication decision for this exact target.

All older tags, release assets, original discs, saves and development outputs
are preserved. Public source additions are inspectable adopted implementation
and ten Korean-only edited records, not a complete standalone game build.
