# V1.05 배포 구성

GitHub의 정식 릴리스 V1.05로 게시합니다. 이전 태그·릴리스·첨부는 변경하거나 삭제하지 않습니다.
배포ZIP은 명시적 허용 목록으로 구성하며 Windows자동 패처, 누적 델타, Python패처,
설치 안내, 변경/검증 문서, 무편집 스크린샷 및 라이선스 고지를 포함합니다.

원본 게임·완성 디스크·BIOS·세이브·에뮬레이터·음원·개인 경로·자격 증명은 포함하지 않습니다.
게시 전 적용 검증과ZIP CRC/체크섬을 확인하고, 게시 후 원격 첨부를 다시 받아 일치 여부를 확인합니다.

이번 제작은 검증된320에 사용자 자막을 적용한321, 이어 8×8 셰리 표기를 고친322입니다.
별도의 전체 소스 재빌드나 전 캠페인 재검증으로 표현하지 않습니다.
정식 배포 결정은 과거 개발 문서의 당시 상태나 미완료 항목을 소급해 바꾸지 않습니다.
