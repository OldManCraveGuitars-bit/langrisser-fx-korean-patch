# V1.1 검증 범위

최종 배포 대상은 successor324입니다. V1.05의 successor322를 해시로 고정한 뒤
RUN 스킵을 적용했습니다. 승인된 successor323-r7과의 차이는 두 MAIN 사본의
타이머 상수 90→72프레임뿐입니다. 약 59.94Hz 기준 1.2초입니다.

## 확인한 내용

- 1,537개 명령 수준 검사: 시간 경계, 버튼 놓기와 재시작 잠금, 모든 이벤트 명령의
  분류, 압축한 원래 함수의 동작 동등성, 선택지 보호, 음성의 기존 취소 처리 등.
- 전투 후 실제 이벤트: 6명의 화자와 세 가지 진영 표시 상태를 거쳐 연속 스킵.
  유닛 퇴장·배치에서 해제되고 누른 채로 다음 대사를 자동 넘기지 않는지 확인.
- 나레이션: 짧은 누르기는 유지, 72프레임을 넘기면 진행, 승리조건 안내에서 정지.
- 실제 게임 진행 영상 002: 짧은 누르기는 유지, 긴 누르기는 원래 정리 경로를 거쳐
  전과보고로 진행. 진입 전 발드 HP만 격리 RAM에서 0으로 설정한 시험 조건을 사용.
- 오마케 영상: 기존 짧은 버튼 스킵과 메뉴 복귀 유지.
- 변경한 RAW 35섹터의 오류정정 및 전체 324,000섹터의 계획 외 바이트 불변 검사.
- 원본 일본판에 Python 패처와 최종 Windows EXE를 각각 적용하여 3개 트랙 전체와
  CUE를 최종 대상과 비교. 설치 도구 11개 테스트와 ZIP 구성·체크섬·CRC 검사.

상세 수치와 파일 확인값은 [검사 기록](verification_V1.1.json)에 있습니다.
과거 V1.05의 모든 검수를 이번에 다시 플레이했다는 뜻은 아닙니다.

## 남은 제한

모든 시나리오·분기·선택지·자연 영상 진입·실기·에뮬레이터를 전수 실행한 것은 아닙니다.
입력 대기 이전에는 길게 누른 시간이 누적되지 않으며, 짧은 자동 페이지는
새 스킵을 시작하기 전에 끝날 수 있습니다. 디스크 I/O와 원래 이벤트 연출은 유지됩니다.
전과보고·통계·캐릭터 후일담은 새 스킵 대상이 아닙니다.

간헐적 엔딩 검은 화면, 전체 숨은 대사의 최종 문맥 검수 및 기존 누적 도구의
실패 8건·오류 1건은 해결을 보증하지 않습니다. 정식판은 배포 구분이지 무결함 인증이 아닙니다.
