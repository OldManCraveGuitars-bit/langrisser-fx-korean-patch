# V1.1 배포 구성

V1.1 정식/최신 릴리스로 배포합니다. V1.05 및 이전 태그·릴리스·첨부는 보존합니다.
Windows 자동 패처, 누적 델타, Python 패처, 설치·변경·검증 안내, 무편집 검수 화면,
신규 코드 선별본 및 라이선스 고지를 허용 목록으로 패키징합니다.

원본 게임·완성 디스크·BIOS·세이브·에뮬레이터·음원·개인 경로·자격 증명은 포함하지 않습니다.
원판 적용 결과를 비교하고 ZIP 멤버·CRC·해시를 확인한 뒤 게시합니다.
게시 후 원격 첨부를 다시 내려받아 로컬 배포 파일과 비교합니다.

사용자가 승인한 연속 스킵 동작을 유지하며 작동 시간만 1.5초에서 1.2초로 낮춘 버전입니다.
정식 배포가 모든 캠페인·분기·기기의 무오류 보증을 뜻하지는 않습니다.
