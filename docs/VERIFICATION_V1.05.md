# V1.05 검증 범위

최종 배포 대상은 successor322입니다. 검증된320을 해시로 고정한 뒤321에 사용자 영상
자막을 반영하고,322에서 8×8 셰리 전용 글자만 수정했습니다.
새 자막은169개, 전용 글자는323개이며 시간 겹침·줄 폭·용량
검사를 통과했습니다. 사용자 저장 JSON은 변경하지 않았습니다.

## 파일과 적용 검사

- 320 대비 변경5012바이트는 자막 임시 업로드 영역과 두 복구 루틴의 전송 길이에 한정됩니다.
- 그 외 모든 바이트가 같으며, 보젤314·상주 글꼴315·질문318·전과보고319·텔레포트320 검사를 유지합니다.
- 수정된 RAW 섹터의 데이터/오류정정과 비수정 영역 동일성을 확인합니다.
- 322의 변경90바이트는 셰리 전용 글자170번의15개 복제본에 한정됩니다.
  이름 레코드145만 이 글자를 참조하며 다른 글자·코드·자막은321과 완전히 같습니다.
- 지원 일본판에서 Python 패처와 최종Windows EXE를 각각 적용하고 전체 결과를322와 비교합니다.
- 공개 패처의11개 테스트, ZIP 구성·멤버 해시·CRC 검사 후 게시합니다.
- 생성된 패치와 EXE, 적용 결과의 확인값은 [기계 검사 기록](verification_V1.05.json)에 수록합니다.

## 실제 실행 증거

- **322:** 새 부팅 후 제공된 게임 내 저장을 로드하여 하단 정보창의 ‘셰리’를 확인.
  RAM이나 기존 상태 저장을 조작하지 않고 최종 디스크의 글자 데이터를 읽어 확인.
- **321:** 새 부팅 및 기존 영상 해금 검수용 내부SRAM 복사본, 자막 카드 없이 영상 선택006·015·016.
  RAM 조작 없이 자막 불변 데이터가 최종 컴파일 결과와 일치하고 영상이 종료됨을 확인.
- **315:** 제공 저장의 엘윈 이동 후 베른하르트 공격·격파. 보젤 두 화면의 음원 유지 및
  다크 프린세스의1회 호출을 빠른/느린 넘김으로 추적. 원본 음원은 보존.
- **318:** 일반 입력으로 질문20개와 선택지60개를 전부 탐색해 화면 및 로드된 문자열 확인.
- **319:** 일본판/한글판에서13번째 적군 깨짐 재현 후 최종319에서13개 포인터 보존,
  마지막 적군·전과보고 종료와 다음 시나리오 메뉴 확인. 정적 용량검사는0~20개.
- **320:** 실제 디스크의 코드로 엘프·바리스타·하이엘프·위치·근접 병사5조건 확인.
  병종과HP만 격리 RAM에서 설정한 시험이며, 공격 연출 피해0·이동 완료·HP 유지 확인.
  97,280개 명령열 검사로 대상 조건 외 메모리 결과 및 레지스터 보존 비교.

315~320의 기존 실행 증거와321의 새 영상 검사는 구분합니다.
모든 과거 시나리오를322에서 다시 플레이했다는 뜻이 아닙니다.

## 남은 제한

간헐적 엔딩 검은 화면은 미해결입니다. 전체 자연 영상/엔딩 분기, 모든 병종·옵션,
실기와 모든 에뮬레이터 검증은 하지 않았습니다. MP 부족 실플레이는 사용자 요청으로 생략했습니다.
원판 텔레포트 오류의 실제 맵 HP 피해는 확인되지 않았습니다.
전체 숨은 대사의 최종 문맥 검수 및 기존 누적 도구 실패8건·오류1건의 해결도 보증하지 않습니다.
정식판은 배포 구분이며 무결함 인증을 뜻하지 않습니다.
