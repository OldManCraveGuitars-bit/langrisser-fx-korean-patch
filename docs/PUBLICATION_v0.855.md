# v0.855 publication scope

The maintainer explicitly requested applying the saved Scenario 15 edit and
publishing the cumulative work as v0.855. This continues the development/
prerelease-review policy for the maintainer and community playtesters. It does
not mark complete human wording review, all branches or console validation done.

Included: the new source-gated delta, version-matched automatic patcher, Python
appliers, installation/changelog/release/implementation/verification documents,
selected project-authored source and Korean-only selected wording, and retained
license notices. Original Japanese catalogs and the personal editor snapshot are
not part of the curated source snapshot. No new game screenshots are added to
this version; historical screenshots remain attributed to their original releases.

Excluded: original/patched BIN/ISO media, original CUE files, BIOS, emulator
executables, SRAM and emulator states, memory dumps, extracted game graphics,
audio/video, private absolute-path reports, backups and authoring catalogs.
The generic patch-output CUE template is retained. Previous versioned patches,
archives, tags and releases are preserved.

Release checks use an explicit archive allowlist, member checksums and readback,
canonical Git-blob manifest, source-copy equality, privacy scans and independent
Python/packaged-EXE application to the supported original dump. The detailed
evidence remains private; public reports disclose only relevant identities,
claims and limits, not personal paths or save names.

The existing MIT license covers project-owned contributions only. It does not
license original game assets or third-party materials. See [license scope](../LICENSE_SCOPE.md).
