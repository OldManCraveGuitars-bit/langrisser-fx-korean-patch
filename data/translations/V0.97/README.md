# Korean-only selected review data

This is the authored successor309 input: 110 selected field-dialogue records
and 18 non-epilogue ending speeches. It is not the entire game/editor catalog,
and does not duplicate the earlier 303–308 review layers.

Identifiers and page/name/control tokens are retained. The private compiler
checks and fits line widths before encoding; this JSON is not directly playable
and is not a replacement for the complete private authoring dependencies.
Japanese extraction catalogs and personal user edits are excluded.
