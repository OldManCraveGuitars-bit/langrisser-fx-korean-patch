# V1.05 실제 화면

모든 이미지는 실제 게임 캡처의 원본 바이트를 그대로 복사했습니다.
크기 변경·색 보정·합성·AI 이미지 생성은 하지 않았습니다.
화면마다 실제 촬영 빌드가 다르며, 이전 검증 빌드의 화면을322의 새 캡처라고 표시하지 않습니다.

- `bozel-fixed.png`:315의 보젤 후속 대사. 정지 화면만으로 음성을 증명하지는 않습니다.
- `report-original.png`:일본판 원작의 마지막 적군 처리 깨짐.
- `report-fixed.png`:319에서 같은 제공 저장을 진행한 전과보고 완료.
- `teleport-fixed.png`:320의 실제 코드로 병종/HP를 격리 설정한 엘프 시험.
- `questions-spaces.png`, `questions-page.png`:318의 전체 질문 탐색 중 반각 공백 및 정찰대 질문.
- `subtitle-*.png`:321 디스크의 영상 선택 메뉴에서 촬영한 수정 자막.322에서 자막은 동일합니다.
- `sherry-8x8.png`:322 최종 디스크를 새로 부팅하고 제공 저장을 불러온 하단 정보창의 셰리.
