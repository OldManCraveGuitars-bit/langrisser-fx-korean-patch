# V0.97 수정·검증 이미지 35장

[수정 리포트](../../docs/RELEASE_V0.97.md)에 모든 사진을 항목별로 배치했다.
파일마다 촬영 빌드, 사용자 제보, 테스트 상태, 수정 전 전용 사진의 구분과 SHA-256을
[provenance.json](provenance.json)에 기록했다. 원본 파일을 그대로 복사했으며 보정,
합성, 크기 변경, 재압축은 하지 않았다.

303~308은 이번 누적 빌드에 포함된 수정의 당시 증거이며 전부 최종309 캡처가 아니다.
38·39번의 진입 화면은 제보 대사 자체의 수정 후 사진이 아니다. 그레이트 소드는
장비 소유 정보를 해제한 별도 테스트 상태다. `사부님` 제보와 `스승님` 참고 화면은
서로 다른 장면이다. MP 부족은 수정 전 사진만 있으며 수정 후 실플레이를 생략했다.
빠른 엔딩 첫 대사는 콜드 실행에서 만든 동일309 상태를 재로드하여 촬영했다.

원작 게임의 그래픽·캐릭터·텍스트와 상표는 해당 권리자에게 속한다. 이 사진 속
원작 자료에는 프로젝트 MIT 라이선스를 적용하지 않는다. 원본 게임·추출 이미지
묶음·세이브·영상·폰트 시트는 함께 배포하지 않는다.
