# V1.1 실제 실행 화면

최종 successor324를 새로 부팅한 격리 에뮬레이터 실행의 무편집 PNG 6장입니다.
정지 화면은 검사한 화면과 정지 지점을 보여 주며 1.2초 타이밍 자체의 증거는 아닙니다.
원본 파일 확인값과 촬영 조건은 `provenance.json`에 기록합니다.

- `narration-before.png`, `narration-boundary.png`: 나레이션과 승리조건 안내. 일반 컨트롤러 입력.
- `dialogue-before.png`, `dialogue-boundary.png`: 베른하르트 격파 후 이벤트와 유닛 퇴장·배치 뒤 정지. 일반 입력 및 제공 SRAM의 격리 복사본.
- `movie-before.png`, `movie-after.png`: 게임 진행 영상 002와 스킵 후 전과보고.
  빠른 진입을 위해 발드 HP만 격리 실행에서 0으로 설정한 뒤 원래 턴 종료·승리 이벤트를 사용.
  배포 게임과 사용자 원본 세이브에는 이 HP 설정을 반영하지 않음.

잘라내기·재압축·합성·텍스트 덧씌우기를 하지 않았습니다. 원작 그래픽·캐릭터·UI의 권리는
원래 권리자에게 있으며 프로젝트 MIT 라이선스로 재허가하지 않습니다.
