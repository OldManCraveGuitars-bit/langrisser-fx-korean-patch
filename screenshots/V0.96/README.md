# V0.96 screenshots

29장 모두 실제 에뮬레이터 화면을 그대로 복사했습니다. 생성형 이미지, 합성,
보정, 재압축을 사용하지 않았습니다. 파일별 빌드와 SHA-256은
[provenance.json](provenance.json)에 기록했습니다.

- `s20-*`: 297 수정 전 / 298 수정 후. 그레이트 드래곤과 좌우 이름 표시.
- `credits-*`, `scott-*`, `inventory-*`: 298/299 수정 전 / 300 수정 후.
- `super-vald-after`, `super-intro-after`: 301 콜드 실행의 누적 수정 근거.
- `super-title-after`: 최종 302의 네이티브 장 선택 로드. 획득한 해금 체크포인트 사용.
- `menu/conditions/capacity/purchase-before`: 이전 비교 빌드. 파일명만으로 최종
  검증 증거로 취급하지 않으며 JSON의 정확한 빌드를 따릅니다.
- 해당 `*-after`, `normal-settings`, `battle-*`, `lich-death`, `rohga-death`,
  `turn8`: V0.96과 같은 최종 302-review5. 구매 확인은 동일 빌드 체크포인트 재개,
  최종 전투는 정상 저장 SRAM 콜드 로드 후 컨트롤러만 사용했습니다.

이전 빌드 캡처가 누적 포함된 수정의 근거라고 해서 최종 V0.96에서 모든 장면을
다시 플레이했다는 뜻은 아닙니다. [수정 보고서](../../docs/RELEASE_V0.96.md)와
[검증 범위](../../docs/VERIFICATION_V0.96.md)를 함께 확인하세요.

원작 캐릭터·게임 그래픽·글꼴 등 화면 속 원작 자료에는 프로젝트 MIT 라이선스를
적용하지 않습니다. 스크린샷은 해당 수정 사항의 설명과 검증을 위한 제한된 자료입니다.
